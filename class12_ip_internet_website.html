Topic 01

What is a computer network?

A computer network is a group of two or more connected computing devices that communicate and share data or resources.

Example: a school lab shares files and a printer over a local network.

Benefits

  • Share files and information
  • Share devices such as printers
  • Communicate quickly
  • Share internet access

Protocols

Protocols are agreed rules that allow devices to communicate and exchange data correctly.

Example: devices use internet protocols to send and receive information.

Remember: a network is a connected system. The Internet is a global network of interconnected networks.

Topic 03

Network devices

Modem

Modulator-demodulator. Adapts signals so data can travel over a communication link. The exact technology depends on the internet connection.

Hub

Connects devices in a LAN and sends incoming data to all its ports.

Switch

Connects devices in a LAN and forwards data to the relevant port, using MAC addresses.

Repeater

Regenerates a weakened signal so it can travel farther.

Router

Connects different networks and forwards packets using IP addresses and routing information.

Gateway

Acts as an entry/exit point between networks; it may translate between different systems or protocols. A home router is often the default gateway.

Quick difference: hub = sends to all ports; switch = forwards within a LAN; router = connects networks; repeater = extends a signal; modem = adapts signals for a link; gateway = connects or translates between systems.
Topic 04

Network topologies

Topology means the arrangement of devices and connections in a network.

Star

Every device connects to a central hub or switch.

Advantage: easy to manage; one device link failing usually affects only that device.

Disadvantage: central device failure can disrupt the network.

Bus

All devices share one main backbone cable.

Advantage: simple and can use less cable in a small setup.

Disadvantage: backbone failure can disrupt the whole network.

Tree

Devices form branches in a hierarchy.

Advantage: easy to expand and group.

Disadvantage: a major upper-level link/device failure can affect a branch.

Mesh

Devices have multiple interconnections. In a full mesh, each connects directly to every other device.

Advantage: multiple paths and high reliability.

Disadvantage: a full mesh is costly and complex.

Topic 05

Internet, WWW and URL

Internet

The Internet is a worldwide system of interconnected networks that communicate using the Internet Protocol suite, commonly called TCP/IP.

WWW (World Wide Web)

The World Wide Web is a service on the Internet: a collection of interlinked web pages and resources accessed using web browsers.

Do not confuse them: the Internet is the global network infrastructure; the Web is one service that uses it. Email and other services also use the Internet.

URL (Uniform Resource Locator)

A URL is the address used to locate a resource on the Web. Example:

https://www.example.com:443/notes/ip.html?unit=network#url

PartExampleMeaning
SchemehttpsMethod for accessing the resource; HTTPS encrypts the connection using TLS.
Domain / hostwww.example.comIdentifies the host/domain.
Port (optional)443Service endpoint; often omitted when default.
Path/notes/ip.htmlIdentifies the resource or route.

Fragment (optional)#urlPoints to a section in the resource.

Domain name: a readable name such as example.com. DNS (Domain Name System) helps translate domain names into IP addresses so devices can locate servers.

Applications of the Internet

Web

Access websites and information using a browser.

Email

Send and receive electronic messages and attachments.

Chat

Exchange messages in near real time, individually or in groups.

VoIP

Voice over Internet Protocol carries voice calls over IP networks. Internet-calling apps may also support video.

Topic 07

Website, webpage, static and dynamic pages

Webpage

A single document or page on the Web, commonly viewed in a browser.

Website

A collection of related webpages and resources, usually managed under one domain.

Topic 08

Web server and web hosting

Web server

A computer and/or software that receives web requests and sends responses, such as webpages, images or data. Examples of server software include Apache HTTP Server and Nginx.

Web hosting

A service that stores a website's files and makes them available over the Internet. It can include storage, server resources and tools for connecting a domain.

Simplified flow: request → server → response → browser displays the result.

  1. You enter a URL or click a link.
  2. The browser locates the server; DNS may resolve the domain name.
  3. The browser sends a request using HTTP or HTTPS.
  4. The server returns the page/data or an error.
  5. The browser interprets the response and displays the result.
Topic 09

Web browsers, settings, add-ons, plug-ins and cookies

A web browser is software used to access and display websites and web applications.

Examples: Google Chrome, Mozilla Firefox, Microsoft Edge, Apple Safari and Opera.

Browser settings

Manage privacy, security, permissions, downloads, appearance, saved passwords and default search engine.

Add-ons / extensions

Optional software that adds or changes browser features, such as a reading helper. Review permissions and use trusted sources.

Plug-ins

Components that historically let browsers handle specific content or functions. Traditional browser plug-ins have largely been phased out in modern browsers.

Cookies

Small pieces of data a website asks the browser to store. They can keep users signed in, remember preferences or support tracking.

Are cookies viruses?

No. Cookies are data, not programs that execute themselves like applications. They can still raise privacy concerns because sites may use them to remember or track activity.

Add-on vs plug-in

An extension/add-on usually adds browser features or changes its interface. A traditional plug-in enabled support for particular kinds of content. Modern browsers rely much less on traditional plug-ins.

Safe browsing: keep your browser updated, check website addresses, review permissions and avoid unknown extensions or suspicious downloads.
